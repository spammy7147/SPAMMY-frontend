# 📋 설계서: 자산(Assets) 페이지 컨테이너 및 함선 접기/펼치기 기능 추가

## 📌 1. 개요
* **문제 상황**: 자산 페이지에서 스테이션이나 구조물은 접을 수 있지만, 그 내부의 함선(Ship)이나 컨테이너(Container)는 접기/펼치기가 불가능하여 자산 목록이 매우 길게 늘어짐.
* **목표**: 함선과 컨테이너 목록에 대해 개별적으로 접고 펼칠 수 있는 토글 기능을 추가하여 가독성을 높임.
* **접근 방식**: 기본적으로 컨테이너는 **접힌 상태**로 로드되며, 클릭 시 펼쳐지도록 구현함. 단, 검색어가 입력된 경우에는 검색된 결과물이 즉시 보이도록 모든 컨테이너가 **자동으로 펼쳐지게** 함.

### 2.2 코드 변경 계획
1. **상태 추가**: 각 컨테이너의 펼침 상태를 저장하는 `expandedContainers` 객체 상태를 선언합니다.
2. **토글 함수 추가**: 컨테이너 ID를 받아 펼침 여부를 반전시키는 `toggleContainer` 함수를 추가합니다.
3. **조건부 렌더링**:
   * 검색어 `searchTerm`이 있으면 무조건 `isContExpanded = true`로 처리합니다.
   * 검색어가 없을 때는 `expandedContainers[cont.id]` 값에 따라 컨테이너 내부 아이템들을 렌더링합니다.
4. **UI 개선**:
   * 컨테이너 헤더 영역을 클릭할 수 있도록 마우스 포인터를 `cursor-pointer`로 변경하고, 마우스 호버 시 배경색이 미세하게 바뀌는 효과(`hover:bg-border/10`)를 줍니다.
   * 컨테이너 이름 왼쪽에 접힘/펼침 여부를 알려주는 화살표 기호(`▼` / `▶`)를 표시합니다.

## 🧪 3. 검증 계획 (Verification Plan)
1. **초기 로드 검증**: 자산 탭에 들어갔을 때, 스테이션은 접힌 상태이고 스테이션을 펼쳤을 때 내부에 📦 컨테이너 아이콘으로 묶인 함선/컨테이너가 접힌 상태로 렌더링되는지 확인합니다.
2. **클릭 토글 검증**: 📦 컨테이너 이름을 클릭했을 때, 내부 적재 아이템(└ 표시 아이템)이 정상적으로 펼쳐지거나 다시 접히는지 확인합니다.
3. **검색 동작 검증**: 검색창에 자산명을 입력했을 때, 해당 자산이 포함된 컨테이너가 자동으로 펼쳐진 상태로 필터링되어 노출되는지 검증합니다.
4. **빌드 검사**: 프론트엔드 빌드(`npm run build`) 및 ESLint 린트가 성공적으로 수행되는지 검증합니다.
